\subsubsection{数据清洗与标准化}
\begin{enumerate}[label=(\arabic*), leftmargin=2.5em, itemsep=0.3em]
\item \textbf{说明数据来源。} 明确数据由赛题附件、公开数据库、文献资料或自主采集获得；使用外部数据时，应在正文和参考文献中注明来源。

\item \textbf{先检查数据质量。} 建模前应分析数据是否存在缺失值、异常值、重复值、格式错误及量纲不一致等问题。

\item \textbf{处理方法要有依据。} 对缺失值填补、异常值剔除、数据平滑等操作，应说明采用的方法和理由，不能随意修改原始数据。

\item \textbf{根据模型需要进行转换。} 若不同指标的量纲、数量级或正负方向不一致，可进行正向化、标准化或归一化处理。

\item \textbf{保留有效信息。} 数据预处理应减少噪声和无效信息，但不能过度处理，更不能为了得到理想结果而人为调整数据。

\item \textbf{保证过程可复现。} 关键处理步骤、参数设置和处理前后的数据变化应交代清楚；较长的程序和完整数据可放入附录或支撑材料。
\end{enumerate}

\textbf{数据预处理的目的，是提高数据质量并满足模型要求，而不是改变数据所反映的客观规律。}

\textbf{常见处理内容}

\ding{172} \textbf{缺失值处理} 根据缺失比例和数据特点，采用删除、均值填补、插值或模型预测等方法。

\ding{173} \textbf{异常值处理} 可通过箱线图、(3$\sigma$) 原则、四分位距或专业阈值识别异常值，并结合实际背景判断是否修正或剔除。

\ding{174} \textbf{数据清洗与转换} 统一日期、单位和数据格式，删除重复记录，必要时进行对数变换、平滑处理或变量编码。

\ding{175} \textbf{无量纲化处理} 评价类和机器学习类问题中，可采用极差标准化、Z-score标准化等方法消除量纲影响。

\textbf{写作提示}

\begin{enumerate}[label=(\arabic*), leftmargin=2.5em, itemsep=0.3em]
\item 只写与后续建模有关的处理步骤，不必罗列所有软件操作。

\item 预处理方法应与数据特点相匹配，避免机械套用固定方法。

\item 建议通过表格或图形展示处理前后的主要变化，但图表不宜过多。

\item 若原始数据质量较好，也应简要说明已完成完整性和异常性检查。
\end{enumerate}

\textbf{写作原则：来源清楚、处理合理、过程透明、结果可信。}
