# 分章写作规范

> 按论文的物理顺序逐章给出「这一章要回答什么问题、必须包含什么、绝对不要写什么」。
> 每章附**参考句式**与**反例**。

**核心心智**：每一章只回答一个问题。章节写偏的根源是作者没想清楚「这一章存在的理由」。

---

## 章节地图

| 顺序 | 章节 | 篇幅参考 | 这一章唯一要回答的问题 |
|------|------|---------|---------------------|
| — | 摘要页 | 1 页（硬上限） | 这篇论文做了什么、得到什么数？ |
| 1 | 问题重述 | 0.5–1 页 | 题目让我干什么？ |
| 2 | 问题分析 | 1–2 页 | 我打算怎么干、为什么这么干？ |
| 3 | 模型假设 | 0.3–0.5 页 | 我在什么前提下建模？ |
| 4 | 符号说明 | ≤1 页 | 我的符号各是什么意思？ |
| 5-7 | 模型的建立与求解 | 主体，逐问 | 数学关系是什么、怎么算出结果？ |
| 8 | 灵敏度 / 误差分析 | 1–2 页 | 结果稳不稳、准不准？ |
| 9 | 模型评价与推广 | 0.5–1 页 | 这模型好在哪、差在哪、还能用在哪？ |
| 10 | AI 使用声明 | 数行 | 是否使用 AI、用于什么？ |
| 11 | 参考文献 | 按需 | 我引用了谁？ |
| 附录 | 文件列表 + 代码 | 不限 | 我的代码在哪、能否复现？ |

> **顺序不可自创。** 这是评阅老师的阅读预期；顺序一变，找结论的成本上升，直接掉印象分。

## 第 1 章 · 问题重述

**要回答**：题目让我干什么？（读者应该能在 1 分钟内理解题意）

### 必须包含

1. **问题背景** — 提炼，不是复制。只保留与建模相关的信息。
2. **已知条件** — 题目给了什么数据、什么约束。
3. **研究任务** — 按问题一、问题二、问题三依次列出。

### 绝对不要

| 禁止 | 原因 |
|------|------|
| ❌ **直接复制赛题原文** | 查重主要检测目标；且暴露「没读懂题、只是搬运」 |
| ❌ 保留故事背景、案例介绍、新闻材料 | 与建模无关的篇幅是浪费 |
| ❌ 添加题目没给的条件 | 篡改题意 |
| ❌ 提前写模型假设或个人理解 | 假设归第 3 章 |
| ❌ 写超过 1 页 | 问题重述不是论文主体 |

### 参考句式

```
问题背景：
随着××的发展，××问题日益突出/成为××领域的关键挑战。题目给出了
××、××等条件，要求我们解决以下问题。

问题提出：
问题一：基于××，建立××模型，求解/预测/评价××。
问题二：在问题一的基础上，考虑××因素，……
问题三：……
```

**B060 式的精炼写法**（背景压到最短）：

> 本文研究红外干涉法测外延层厚度问题。题目给出附件 1~4 的反射率测量曲线，
> 要求：（1）建立反射率与外延层厚度的关系模型；（2）……；（3）……

### 自检

- [ ] 用自己的话写的（逐句对照赛题，确认无整句雷同）
- [ ] 篇幅 ≤ 1 页
- [ ] 三个问题与后文「模型建立与求解」一一对应，编号一致

## 第 2 章 · 问题分析

**要回答**：我打算怎么干、为什么这么干？（**不写结果**）

> 模板原话：「问题分析的目的，是告诉评阅老师：**为什么这样建模**，而不是**模型怎么算**。」

### 每问的四个动作

| 动作 | 内容 |
|------|------|
| ① 明确问题类型 | 属于**评价 / 预测 / 分类 / 优化 / 决策 / 机理分析**哪一类？ |
| ② 分析关键因素 | 影响结果的主要变量、约束条件、可用数据是什么？哪些需重点考虑？ |
| ③ 确定建模思路 | 适合哪类模型/算法，**并说明选择理由** |
| ④ 说明求解目标 | 最终要输出什么：最优方案 / 预测值 / 评价结果 / 分类结果？ |

### 高阶技巧：写出问题之间的数学依赖

问题分析的质量分水岭在于——**是否显式写出前一问的结果如何成为后一问的输入**。

**B195 的示范**：

> 显然问题三是对问题二的推广，对于每种零配件、每种半成品、成品都存在一个
> 决策参数，即是否检验……设立决策变量矩阵后，再仿照问题二的思路进行模拟
> 退火，得到最优的决策矩阵。

一句话完成了三件事：定性关系（推广）、规模变化（维度增加）、复用路线（照问题二思路）。

### 绝对不要

| 禁止 | 原因 |
|------|------|
| ❌ 写求解结果 | 结果归第 5-7 章，提前给出会打乱叙事 |
| ❌ 推导公式 | 公式归模型建立章 |
| ❌ 罗列一堆模型名称 | 「本文使用了 AHP、TOPSIS、熵权法、神经网络、遗传算法……」= 没做选择 |
| ❌ 为用某模型而牵强分析 | 「先分析问题，再选择模型」，不是倒过来 |

### 自检

- [ ] 每一问都有「问题特点 → 关键因素 → 建模思路 → 预期结果」四段
- [ ] 模型选择都给了理由（不是「因为常用」）
- [ ] 未出现任何计算结果
- [ ] 与后文模型建立章的模型**完全一致**（不能这里说用 A，那里用了 B）

## 第 3 章 · 模型假设

**要回答**：我在什么前提下建模？

> 模板原话：「模型假设不是随意简化，而是在**保证主要规律不变**的前提下，忽略次要因素。」

### 四条铁律

1. **每条假设必须服务于建模** — 能对应到后文用到的某个模型机制。写一条从不被使用的假设 = 凑篇幅。
2. **每条必须具体** — 说明**具体忽略了什么、保持什么不变**。
3. **数量克制** — 4~6 条为宜，不超过 8 条。
4. **后文一致** — 模型建立、参数设置、结果分析必须遵循已提假设；若关键假设可能影响结果，**必须做灵敏度分析**。

### 参考句式（真实获奖论文）

```
（1）假设××随机分布，以避免××的集中扎堆情形。
（2）假设××过程中，由于工艺出现××的概率是随机的。
（3）假设××时，若部分××，则随机地选择部分××。
（4）假设若不能回收××，则直接丢弃不会造成××费用。
（5）假设××的多个环节都会影响××，但均抽象成一个××。
（6）假设生产规模较大，本文仿真起始均使用 10000 套零件。
```

```
1. ××只有两种状态：××只有合格品和次品两种状态，没有其他中间状态，
   即服从二项分布。
2. ××和××固定：不随××和××的变化而变化。
3. ××流程是线性的：即××经过××、××、××等环节后，最终成为××。
4. ××参数：模型中涉及多个算法参数，例如××中的××、××中的××等，
   这些参数的设置需要根据实际情况进行调整。
```

### 反例对照

| ❌ 坏假设 | 问题 | ✅ 改法 |
|----------|------|--------|
| 假设其他条件均不变 | 什么信息都没给，无法检验 | 假设研究期内原材料单价保持不变 |
| 不考虑特殊情况 | 笼统到无法操作 | 假设设备运行状态正常，不发生突发故障 |
| 假设所有数据都是准确的 | 回避了误差问题 | 假设测量误差服从均值为零的正态分布 |
| 把题目已给条件重抄成假设 | 冗余 | 直接删 |

### 自检

- [ ] 每条能指到后文某个具体用到的机制
- [ ] 每条都具体到「忽略了什么」
- [ ] 没有「其他条件不变」这类空话
- [ ] 关键假设都在灵敏度分析里被检验过

## 第 4 章 · 符号说明

**要回答**：我的符号各是什么意思？

### 格式

三线表：**符号 | 说明 | 单位**

- 有单位的必须标单位；无量纲填 `\` 或留空
- 符号 **> 15 个**时按字母族分组（拉丁字母 / 希腊字母）或按物理量类别分组

### 五条规则

1. **只列重要符号** — 正文中多次使用、含义关键的变量/参数/指标。临时变量不入表。
2. **一一对应** — 每个符号说明具体含义，必要时标单位。
3. **全文统一** — 同一符号在不同章节**必须**表示同一含义；不要一符多义，也不要多符同义。
4. **符号规范** — 变量斜体；向量、矩阵、集合按全文习惯统一（见 `03-格式技术规范.md` §3.4）。
5. **首次出现仍要解释** — 即使表里列了，正文首次使用时也简要说明。

### 篇幅

**≤ 1 页。** 符号表溢出到第二页说明你在把临时变量也塞进去。

### 反例

```
❌  a    一些参数
✅  a    第 i 种零件的次品率
```

### 自检

- [ ] 表中每个符号在正文都被用到
- [ ] 正文核心符号都在表中
- [ ] 无「一符多义」
- [ ] 单位列完整
- [ ] ≤ 1 页

## 第 5-7 章 · 模型的建立与求解（按问分章）

**要回答**：数学关系是什么、怎么算出结果？

> 模板原话：「**模型建立**回答"数学关系是什么"，**模型求解**回答"如何得到结果"。」

### 推荐的子节结构

```
5.1 问题一模型的建立与求解
    5.1.1 数据预处理          （若有数据：缺失值/异常值/标准化）
    5.1.2 求解思路            （可用流程图；不写公式细节）
    5.1.3 模型的建立          （变量定义 → 目标函数 → 约束条件）
    5.1.4 模型的求解与结果分析 （算法、参数、结果表格、结果解读）
```

### 建立模型的四个动作

| 动作 | 要求 |
|------|------|
| ① 确定变量与参数 | 说明输入数据、**决策变量**、状态变量、主要参数的含义 |
| ② 建立数学模型 | 给出目标函数、约束条件、评价指标或变量关系，**并说明公式的实际意义** |
| ③ 选择求解方法 | 所用算法 + **选择理由** + 主要计算步骤 + 关键参数设置 + 终止条件 |
| ④ 展示求解结果 | 表格/图形呈现核心结果，**并围绕题目要求进行解释** |

### 杀手锏一：加性分解（用 B196 的真实结构示范）

把总目标拆成**互不重叠的分项**，每项一个公式、一句符号解释：

```
1. 成本计算

                                       W_{1i} 表示第 i 种零件的购买单价。

                                       D_{1i} 表示检测决策，取 0 为不检测，取 1 为检测。
   （3）成品装配成本 C₃   → 式(10)(11)
   （4）成品检测成本 C₄   → 式(12)
   （5）成品拆解成本 C₅   → 式(13)
   （6）用户调换成本 C₆   → 式(14)
2. 收益计算
   收益仅与客户所收到合格品的数量有关 → 式(15)
```

**成本 → 收益 → 利润**，三步闭合，不跳步。

### 杀手锏二：决策变量 0/1 化

决策类题目（检测/不检测、拆解/不拆解、选择/不选择）的标准动作：

> 把管理决策编码为 $D_i \in \{0,1\}$，写作「$D_{1i}$ 表示第 i 种零件的检测决策，
> 取 0 为不检测，取 1 为检测」。

好处：决策问题立刻变成**组合优化问题**，可直接套遗传算法/模拟退火/蚁群算法。

### 杀手锏三：交叉验证

**存在两条以上独立求解路径时，务必都做出来并列呈现。**

B060 的示范：

```
路线（1）周期波谷直接计算法 → d = 7.544 μm
路线（2）牛顿迭代反演法     → d = 7.295 μm
→ 作为直接计算值 7.544μm 的较好印证值
```

两条独立路径收敛到同一量级，可信度显著提升。评阅老师看到「交叉印证」就知道作者有科学素养。

### 绝对不要

| 禁止 | 原因 |
|------|------|
| ❌ 大段复制教科书的方法介绍 | 不产生「本文做了什么」的信息，稀释你的贡献 |
| ❌ 公式堆砌无文字解释 | 评委无法判断你是否理解 |
| ❌ 只给结果不解释实际含义 | 数字本身没有意义 |
| ❌ 程序代码大段入正文 | 核心流程用流程图/伪代码，完整代码放附录 |
| ❌ 无意义的过高精度 | 「7.5439821μm」的 7 位有效数字毫无意义 |
| ❌ 图表无编号、无标题、无坐标单位 | 见 `03-格式技术规范.md` §3.3 |
| ❌ 图表在正文中不被引用、不被分析 | 图是证据，不是装饰 |

### 通用方法介绍的压缩写法

```
❌ 决策树法是一种通过树状图形来分析和选择决策方案的方法，它将决策问题分解为
   一系列节点和分支，每个节点代表一个决策或机会，分支则表示不同选择带来的结果。
   通过计算各结果的期望值，决策者可以从中选出最优的决策路径。（60 字，零信息量）

✅ 决策树法通过计算各分支期望值选择最优路径[3]。在处理问题二时，我们将其抽象化
   为四个关键的决策节点：零件 1 的质量检验、零件 2 的质量检验、最终产品的质量
   检验，以及对于不合格成品的拆解处理。（把篇幅让给本题特有的建模动作）
```

### 自检

- [ ] 每个公式后有符号解释 + 实际意义
- [ ] 决策变量有明确定义域（如 0/1）
- [ ] 算法给了**选择理由**，不只给了名字
- [ ] 结果有数值、有单位、有实际含义解读
- [ ] 每张图/表都在正文被引用并分析过
- [ ] 与第 2 章的问题分析保持一致

## 第 8 章 · 灵敏度分析与误差分析

**要回答**：结果稳不稳、准不准？

> 模板原话：
> **灵敏度分析**关注「**参数变化会使结果改变多少**」→ 检验**稳定性和鲁棒性**。
> **误差分析**关注「**模型结果与实际值相差多少**」→ 检验**准确性和可信度**。

### 检验三件套（缺一类，检验就不完整）

| # | 检验类型 | 回答的问题 | 常用手段 |
|---|---------|-----------|---------|
| 1 | **灵敏度分析** | 参数变化时结论是否还成立？ | 单参数 ±5%/±10% 扰动、多参数联动、情景分析 |
| 2 | **误差 / 稳定性分析** | 结果与真实值差多少？ | 绝对/相对误差、MSE、MAE、拟合优度、置信区间、变异系数 |
| 3 | **对比验证** | 换个方法算，结果一致吗？ | 两条独立解法互证、不同算法对比、与文献基准对比 |

> 💡 **关于「模型检验是否要独立成章」**：实测显示独立成章的比例并不高——很多优秀论文
> 把检验内容**并入每一问的结果之后**，而不是单开一章。
> **结论：检验内容几乎必须要有，但形式可以灵活**（独立成章 or 每问附带均可）。
> 本模板采用独立章节（第 8 章），因为它最容易让评委找到。

### 灵敏度分析五步

1. **选择关键参数** — 优先分析取值不确定、对模型结构影响大、或来源于人为设定的参数。
2. **合理设置变化范围** — 基准值附近按比例调整，如 ±5%、±10%，或符合实际的范围。
3. **保持其他条件不变** — 每次只动一个参数，观察目标值/评价结果/排序/**最优方案**的变化。必要时分析多参数共同影响。
4. **展示变化规律** — 表格、折线图或柱状图表示「参数变化 ↔ 结果」关系。
5. **判断模型稳定性** — 小幅变化→结果变化小 = 稳定；变化明显→**指出敏感参数并分析原因**。

### 误差分析五步

1. **明确误差来源** — 原始数据、测量过程、缺失值处理、参数估计、模型简化、数值计算。
2. **选择误差指标** — 绝对误差、相对误差、MSE、MAE、拟合优度等。
3. **进行结果对比** — 与真实值、历史数据、题目给定结果、或其他合理方法的结果比较。
4. **分析误差大小** — 是否在可接受范围？结合背景解释偏差原因。
5. **指出模型局限** — 误差较大时，说明模型在哪些条件下可能失效、如何改进。

### ⚠️ 最容易犯的错

**只给图表，不给结论。**

灵敏度分析的结论必须落到「**决策是否改变**」或「**方案是否仍然可行**」上。

**B196 的真实示范**：

> 通过对比 95% 和 90% 置信度下的最优决策分布发现，在次品率较高时，决策倾向于
> 更多的检测操作以减少次品带来的损失。进一步分析了在不同次品率条件下各决策
> 分支对利润的影响，发现零件 3、4、8 检测以及成品检测对次品率变化较为敏感。
> 综合考虑，在抽样检测条件下，建议检测所有零件与半成品，不检测成品，并拆解
> 所有次品，以确保在极端情况下仍能获得可观利润并降低调度损失的风险。

三个动作：**对比不同条件 → 指出敏感变量 → 给出鲁棒结论**。

### 缺数据时的替代方案

若缺少真实数据无法直接计算误差，**如实说明**，并采用：
- 交叉验证
- 历史回代
- 情景分析
- **两条独立解法的结果对比**（见第 5-7 章"交叉验证"）

### 自检

- [ ] 至少给出一个参数变化范围（不是"做了一次计算就说稳定"）
- [ ] 有明确的稳定性/准确性**结论句**
- [ ] 敏感参数被点名并解释了原因
- [ ] 结论与模型假设呼应

## 第 9 章 · 模型评价与推广

**要回答**：这模型好在哪、差在哪、还能用在哪？

> 模板原话：「本部分主要体现对模型的全面认识，**不是论文重点**，做到分析客观、
> 内容精炼即可。」篇幅 **0.5–1 页**。

### 最高频的扣分点：空泛套话

**一句话判据（最可靠的自检方法）**：

> **把论文标题遮住。如果这段评价放到任何一篇论文后面都"说得通"，那就是套话；
> 如果它必须提到本模型才成立，才是合格评价。**

**真实获奖论文的合格范例**（官方优秀论文 B060 第 7 章原文摘录）：

> - **物理基础扎实**：模型从**菲涅尔公式**出发，结合 **Drude 折射率模型**与光学声子修正项，
>   较完整地刻画了材料在中远红外波段下的光学性质。
> - **方法多样互补**：**周期波谷直接计算法**和**牛顿迭代反演法**各具优势。前者提供厚度的
>   显式公式，计算简洁直观；后者通过迭代优化拟合实验曲线，精度更高。**两者结果能够相互印证**。
> - **多光束效应分析全面**：引入多光束干涉的等效反射率表达式和**表征参数 G**，建立了
>   **定量判断标准**。
> - **结果可信度高**：计算过程中引入统计分析（**均值、标准差、置信区间、变异系数**等）。
>
> 五条优点**全部锚定在本模型的具体构件上**（菲涅尔公式、Drude 模型、参数 G、统计指标），
> **没有任何一条可以原样搬到另一篇论文**。

**对照表**：

| ❌ 套话（放在任何论文里都成立） | ✅ 绑定本文机制 |
|-------------------------------|----------------|
| 本模型精度高、效果好 | 本模型将连续的光谱测量转化为离散的波谷周期计数，避免了对折射率初值的依赖，两条独立路线的结果偏差仅 3.3% |
| 本模型适用性强 | 本模型对任意多层膜结构均可推广，只需替换 Fresnel 反射系数矩阵 |
| 本模型计算效率高 | 牛顿迭代在 5 次迭代内收敛，单条曲线耗时 < 0.1 s，可支撑批量检测场景 |
| 本模型存在一定不足 | 本模型假设入射光为完全偏振光（s 光与 p 光各占 50%），对实际部分偏振的入射条件会产生系统性偏差 |
| 参数依赖经验 | 折射率模型所需的材料参数多取自文献，实际样品的厚度、掺杂、表面粗糙度等因素未完全纳入 |

### 缺点的写法：三段式「缺陷—影响—改进」

不要只承认缺陷（自我否定），也不要掩饰缺陷。按三段式写：

```
先指出【具体缺陷】 → 再说明【影响范围】 → 最后给【改进方向】
```

**示例**：

> 本模型将局部地形简化为平面（缺陷），在坡度剧烈处会低估覆盖宽度变化（影响），
> 可进一步采用局部二次曲面或沿测线实时更新坡度（改进）。

**两条约束**：
- ⚠️ **不写致命缺陷**——不要承认模型的根本性错误，只写可改进的局限。
- ⚠️ **优点数量应多于缺点**——通篇自我否定会让评委怀疑模型的有效性。

### 优缺点必须一一对应

模板明确要求：「**优点和缺点应一一对应**，评价要有依据，不宜过分夸大或刻意贬低。」

推荐写法：

```
优点 1：××方法使模型具备××能力
缺点 1：但该方法要求××前提；当××不成立时，需改用××

优点 2：模型参数少，全部可由数据标定
缺点 2：代价是忽略了××的时变特性，在长时间尺度上可能失效
```

### 四个可评价的维度

| 维度 | 问自己 |
|------|--------|
| **科学性/合理性** | 模型是否真实描述实际问题？ |
| **可解释性** | 变量和参数是否有明确实际意义？ |
| **计算效率** | 算法是否收敛快、复杂度是否低？ |
| **稳定性与通用性** | 参数小范围变化时结果是否稳定？能否用于同类问题？ |

### 模型推广的写法

推广必须**立足于本文模型**，不要脱离论文内容空谈。

```
【推广】在××方面，可以将××参数替换成××参数，从而解决××问题。
【改进】结合参考文献[×]，进一步考虑××的影响，从而得到更合理的模型。
```

### 篇幅底线

模板提示：「这部分不用太多，**至少 4 行**。」但也不要超过 1 页——它不是论文重点。

### 自检

- [ ] 优点和缺点一一对应
- [ ] 每条评价都绑定了本文模型的具体机制
- [ ] 「本模型」→「任何模型」替换测试：套话已被清除
- [ ] 推广立足本文模型
- [ ] 篇幅 0.5–1 页

## 第 11 章 · 参考文献

### 规范第七条

「所有引用他人或公开资料（包括网上资料）的成果必须按照科技论文的规范列出
参考文献，**并在正文引用处予以标注**。」

### 三种格式（规范原文）

```
书籍：
[编号] 作者，书名，出版地：出版社，出版年.

期刊论文：
[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年.

网上资源：
[编号] 作者，资源标题，网址，访问时间（年月日）.
```

### 🔴 最重要的一条

> **只允许引用真实存在的文献。**

编造参考文献是学术不端，且评阅老师会抽查。每一条文献必须：
- [ ] 真实存在，能检索到
- [ ] DOI / 期刊卷期号 / 页码准确
- [ ] 内容与你的引用语境相符（不要引一篇不相关的论文凑数）

### 数量参考

- 太少（< 5 条）显得没有文献调研
- 太多（> 30 条）且集中在通用方法介绍上，显得在凑数
- **推荐 10~20 条**，每一条都对应正文中一个真实的引用需求

### 自检

- [ ] 每条文献真实存在（逐条查证）
- [ ] 正文每个 `[n]` 都能在列表中找到
- [ ] 列表中的每一条都在正文被引用过（无"僵尸文献"）
- [ ] 按正文引用顺序编号
- [ ] 引用书籍时标了页码

## 附录 · 写作时长的分配建议

> 以下为经验值，来自竞赛实践，非官方规定。

三天赛程的常见分配：

| 时间 | 建模/求解 | 论文写作 |
|------|----------|---------|
| 第一天 | 选题、查资料、确定思路 | **搭好 LaTeX 骨架**（章节标题占位），写好"问题重述" |
| 第二天 | 主力求解问题一二 | 每完成一问立刻写一节；图表随做随入 |
| 第三天上午 | 完成问题三 / 灵敏度分析 | 写完问题分析、模型假设、符号说明 |
| 第三天下午 | 复核数值 | **写摘要**（最重要的一页，必须最后写、反复改） |
| 第三天晚上 | — | 模型评价与推广、参考文献、附录代码、格式与匿名检查 |

**关键原则**：
1. **论文不是最后一天写的。** 从第一天就开始写，边做边写。
2. **摘要必须最后写**，且要预留 ≥ 2 小时反复打磨。
3. **格式检查留足 1 小时**（对照 `03-格式技术规范.md` §四的清单）。
