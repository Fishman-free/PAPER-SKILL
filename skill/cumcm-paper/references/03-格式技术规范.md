# 格式与技术规范

> 本文档的硬性规定来自**《全国大学生数学建模竞赛论文格式规范（2026 年修订稿）》**十三条原文。
> 查重红线、AI 使用规定、参赛规则见 `02-评阅标准与红线.md`。
>
> ⚠️ **页数口径提示**：2023 修订稿写「正文尽量控制在 20 页以内」，**2026 修订稿写「不超过 30 页」**。
> 本文档以 2026 修订稿为准。**赛前务必核对当届原文。**

---

## 一、官方硬性规范（违反 = 可能取消评奖资格）

### 1.1 纸质版（第一至八条）

| 条 | 规定 | 要点 |
|----|------|------|
| 一 | 白色 A4 纸打印（单面、双面均可） | **上下左右各留至少 2.5 厘米页边距**；从左侧装订 |
| 二 | 第一页为承诺书，第二页为编号专用页 | 内容见相关专用页 |
| 三 | 第三页为摘要专用页 | 摘要内容（含标题和关键词，**无需翻译成英文**）**原则上不能超过一页** |
| 三 | 页码 | 从**摘要页开始**编写页码，位于**页脚中部**，阿拉伯数字从「1」开始**连续编号** |
| 四 | 正文从第四页开始 | **不要目录**；**正文不超过 30 页**；正文之后是附录，**附录页数不限**，附录必须打印并装订提交 |
| 五 | 附录内容 | 必须包含：① 支撑材料的文件列表 ② 建模所用到的**全部完整、可运行的源程序代码**（含 EXCEL、SPSS 等软件的交互命令） |
| 五 | ⚠️ 后果条款 | **缺少必要的源程序、程序不能运行、或运行结果与论文不符，都可能被取消评奖资格** |
| 五 | 无程序的情形 | 若确实没用到程序，须在附录中明确说明「本论文没有用到程序」 |
| 六 | ⚠️ 匿名 | 摘要专用页、正文和附录中**任何地方都不能有显示参赛者身份和所在学校及赛区的信息** |
| 七 | 引用 | 所有引用他人或公开资料（包括网上资料）的成果必须按科技论文规范列出参考文献，**并在正文引用处予以标注** |
| 八 | 自由度 | 字号、字体、行距、颜色等不做统一要求；各赛区在不违反本规范前提下可另行要求 |

### 1.2 电子版（第九至十一条）

| 条 | 规定 | 要点 |
|----|------|------|
| 九 | 提交两个文件 | 参赛论文 + 支撑材料 |
| 十 | 一致性 | 电子版内容必须与纸质版**完全一致**（包括附录）；必须是**单独的一个文件**；格式为 PDF 或 Word 之一（**建议 PDF**）；**文件大小不超过 20MB** |
| 十 | 不要压缩 | 电子版论文文件不要压缩 |
| 十 | ⚠️ 第一页 | **承诺书和编号专用页不要放在电子版论文中**，即**电子版论文的第一页必须为摘要专用页** |
| 十一 | 支撑材料 | 内容：支撑模型/结果/结论的所有必要材料，至少包括所有可运行源程序、自主查阅使用的数据资料（赛题原始数据除外）、较大篇幅中间结果的图表 |
| 十一 | 打包 | 用 WinRAR 压缩在**一个文件**中（RAR 或 ZIP，**不超过 20MB**） |
| 十一 | 文件列表 | 支撑材料的**文件列表应放入论文附录** |
| 十一 | 无支撑材料 | 可提供「本论文没有支撑材料」的说明 |
| 十一 | ⚠️ 一致性 | **支撑材料文件与论文内容不相符，可能被取消评奖资格** |
| 十一 | ⚠️ 匿名 | 承诺书和编号专用页不要放进支撑材料；所有文件中不能有身份/学校/赛区信息 |

### 1.3 规范的效力（第十二、十三条）

- 本规范自发布之日起试行，**与旧规范不一致的以本规范为准**。
- **不符合本规范的论文将被视为违反竞赛规则，可能被取消评奖资格。**
- 解释权属全国大学生数学建模竞赛组委会。

> 官网：`mcm.edu.cn`。**每年赛前必须重新核对当届规范。**

### 1.4 ⚠️ 赛区可以加码（第八条明文授权）

规范第八条：**「在不违反本规范的前提下，各赛区可以对论文做相应的要求。」**

这意味着：**全国规范是下限，不是全部要求。** 部分赛区会自设更严的规定（更严的查重阈值、
额外的格式要求、特殊页数限制等）。

> **行动项**：赛前必须同时查阅**全国规范**和**所在赛区的补充通知**。

### 1.5 ⚠️ 字体字号：官方不做统一要求

规范第八条原文：**「本规范中未作规定的，如论文的字号、字体、行距、颜色等不做统一要求。」**

因此：

| 说法 | 定性 |
|------|------|
| 「正文宋体小四」「一级标题三号黑体」 | ⚠️ **惯例，非官方硬性要求**（各赛区/高校可能另有规定） |
| 「学位论文规范要求」 | ❌ 不适用——学位论文规范与竞赛规范是两套文件 |
| 「必须 300 dpi 以上」 | ⚠️ 来自其他赛事与期刊规范，**不是国赛规定** |
| 「上下左右各留至少 2.5 厘米」 | ✅ **官方硬性**（第一条） |
| 「页码在页脚中部，从摘要页开始」 | ✅ **官方硬性**（第三条） |

**结论**：字体字号按模板默认或赛区要求执行即可，**不必为了"合规"纠结字体**——官方根本没规定。
把精力放在真正有硬性要求的地方（页边距、页码、页数、匿名、附录代码）。

## 二、匿名要求：最容易踩的致命坑

**规范第六条规定摘要页、正文、附录任何地方都不能出现身份/学校/赛区信息。**

这条是硬红线，但每年都有人栽在细节上——尤其是**元数据**和**代码注释**。

### 匿名自查清单（提交前逐条过）

**正文层面**
- [ ] 页眉页脚无学校名、无队号
- [ ] 封面/标题页无姓名、无学号（电子版根本没有承诺书页）
- [ ] 正文中未出现「我校」「本团队」「XX 大学实验室」等表述
- [ ] 致谢部分（如有）不出现导师/学校信息，或直接删除致谢

**代码层面（最常被忽略）**
- [ ] **代码注释里的路径**：`D:\Users\张三\...`、`/home/teamname/...` 必须清理
- [ ] **代码里的作者信息**：文件头注释、`__author__` 字段、IDE 自动生成的模板注释
- [ ] **Jupyter Notebook 的输出残留**：执行路径、环境变量输出
- [ ] **日志文件**：脚本运行日志里可能带绝对路径

**元数据层面（最隐蔽）**
- [ ] **图片元数据**：截图和导出图里的窗口标题栏、任务栏、文件名
- [ ] **Excel/CSV 元数据**：作者字段、最后保存者字段
- [ ] **PDF 元数据**：标题、作者、创建者字段（导出时清空）
- [ ] **Word 元数据**：作者、公司、最后修改者

**文献层面**
- [ ] 参考文献中未出现「本文作者前期工作」的自引暴露

> 💡 本 skill 的 `scripts/check_paper.py` 可自动扫描正文与 LaTeX 源码中的身份泄露特征。

## 三、LaTeX 与排版实践

### 3.1 编译方式

模板使用 `cumcmthesis` 文档类，**必须用 XeLaTeX 编译**：

```bash
xelatex main.tex
xelatex main.tex   # 第二次用于生成正确的引用与页码
```

若使用 bibtex 参考文献：`xelatex → bibtex → xelatex → xelatex`。

### 3.2 电子版与纸质版的差异处理

模板 `cumcmthesis` 提供了开关：

```latex
\documentclass{cumcmthesis}                          % 纸质版：含承诺书与编号页
% \documentclass[withoutpreface,bwprint]{cumcmthesis} % 电子版提交时使用
```

**⚠️ 电子版必须使用 `withoutpreface`**，否则第一页不是摘要页，直接违反第十条。

### 3.3 图表规范

| 项目 | 规范 |
|------|------|
| 图题位置 | **图下方**，形如「图 1  t(n) 分布分位点示意图」 |
| 表题位置 | **表上方**，形如「表 1  符号说明」 |
| 编号 | 全文连续编号（图 1、图 2…；表 1、表 2…），按出现顺序 |
| 图内文字 | 字号不小于正文，保证打印后可读 |
| 坐标轴 | 必须有轴标签 + **单位** |
| 三线表 | 顶线最粗、底线次之、中线最细 |
| 表格宽度 | 建议 `0.7\textwidth` 左右 |
| 分辨率 | 位图 ≥ 300 dpi；矢量图（PDF/EPS）优先 |
| 引用 | 正文**必须**用「如图 X 所示」「如表 X 所示」显式引用，并**对其内容作出分析** |

**三线表的 LaTeX 写法**（模板已提供）：

```latex
\begin{tabularx}{0.7\textwidth}{ccc}
    \toprule[1.5pt]      % 顶线最粗
    符号 & 含义 & 单位 \\
    \midrule[1pt]        % 中线次之
    ...
    \bottomrule[1.5pt]   % 底线最粗
\end{tabularx}
```

### 3.4 公式规范

- **行间公式居中，编号右对齐**（`\begin{equation}` 自动编号）
- 正文引用写作「式（1）」「由式（3）可得」
- 字母约定：

| 类型 | 排版 | LaTeX |
|------|------|-------|
| 变量 | *斜体* | `$x$`、`$d$`、`$n$`（数学模式默认） |
| 函数名 | **正体** | `\sin`、`\log`、`\max` —— **不要写 `sin`、`log`** |
| 矩阵/向量 | **粗体** | `\mathbf{x}` 或按全文统一约定 |
| 单位 | **正体** | `\mathrm{\mu m}` 或 `\text{ μm}` —— **不要用斜体写单位** |
| 多字母变量名 | 按约定 | `\mathit{abc}`，避免被排成 $a\cdot b\cdot c$ |

- 长公式换行对齐用 `\begin{align}` + `&=`。
- ⚠️ **每个公式后必须解释符号**：「其中 $N_i$ 表示第 i 种零件的购买数量。」

### 3.5 参考文献格式（规范第七条）

规范指定的表述方式：

```
书籍：
[编号] 作者，书名，出版地：出版社，出版年.

期刊论文：
[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年.

网上资源：
[编号] 作者，资源标题，网址，访问时间（年月日）.
```

现代写法（模板提供）—— GB/T 7714-2015 数字顺序制：

```latex
\bibliographystyle{gbt7714-numerical}
\bibliography{references}
```

> 🔴 模板注释中明确写着：「**只允许引用真实存在的文献**」。
> 编造文献是学术不端，且评阅老师会抽查。

## 四、提交前最终检查清单

### 4.1 文件层面

- [ ] 电子版论文为**单个 PDF**，第一页是摘要页（无承诺书/编号页）
- [ ] PDF **不超过 20MB**，未做有损压缩
- [ ] 支撑材料为**单个 RAR/ZIP**，不超过 20MB
- [ ] 支撑材料的**文件列表已放入论文附录**
- [ ] 附录含**全部完整可运行源代码**
- [ ] 附录代码**实际运行过**，输出结果与论文一致（规范第五条）
- [ ] 若使用 AI 工具，支撑材料中附有《**AI工具使用详情.pdf**》（见 `02-评阅标准与红线.md` §五）

### 4.2 内容层面

- [ ] 摘要**不超过一页**
- [ ] 摘要含标题 + 摘要 + 关键词，**无英文摘要**
- [ ] 正文**不超过 30 页**
- [ ] **无目录**
- [ ] 从摘要页开始编页码，页脚中部，从 1 连续编号
- [ ] 每个引用处有 `[n]` 标注，参考文献列表按引用顺序
- [ ] 所有文献真实存在（逐条验证）

### 4.3 匿名层面

- [ ] 全文搜索「大学」「学院」「老师」「我们组」「队长」「学号」，逐个确认
- [ ] 代码文件头、注释、路径无身份信息
- [ ] 图片无窗口标题栏/任务栏/文件路径
- [ ] PDF 元数据（作者/标题）已清空
- [ ] 支撑材料内所有文件同样检查

### 4.4 一致性层面

- [ ] 论文中的数值结果与附录代码输出**一致**
- [ ] 支撑材料文件与论文内容相符（规范第十一条）
- [ ] 符号表、正文、附录中的符号含义一致
- [ ] 图表编号连续，无跳号、无重复

## 五、自动化检查

本 skill 提供校验脚本，把上述硬约束变成可执行检查：

```bash
# 检查 LaTeX 源码（推荐，最早发现问题）
python scripts/check_paper.py --latex main.tex --chapters chapter/

# 检查纯文本
python scripts/check_paper.py --text paper.txt

# 检查 PDF
python scripts/check_paper.py --pdf paper.pdf
```

脚本会检查：`withoutpreface` 开关、目录、摘要环境、AI 声明、附录与代码、参考文献与 `\cite`、图表 caption、身份信息泄露、占位符未填写、模糊表述、PDF 元数据。

> **脚本不能替代人工检查**，尤其是：内容一致性、文献真实性、代码可运行性。

## 六、常见违规后果速查

| 违规 | 后果 |
|------|------|
| 缺少必要源程序 / 程序不能运行 / 结果与论文不符 | **可能取消评奖资格** |
| 论文中出现身份、学校、赛区信息 | 违反第六条（匿名要求） |
| 支撑材料与论文内容不符 | **可能取消评奖资格** |
| 不符合格式规范（版面、页数、摘要页等） | **可能取消评奖资格** |
| 引用未标注 | 违反第七条 |
| 相似度任一库 ≥ 25% | 原则上不能报送全国评阅（见 `02`） |
| AI 使用未声明 / 虚假声明 | **取消评奖资格**（见 `02`） |

> 规范第十二条原文：「不符合本规范的论文将被视为违反竞赛规则，可能被取消评奖资格。」
>
> 这不是「扣几分」的问题，是**资格问题**。**格式规范永远优先于内容打磨。**
