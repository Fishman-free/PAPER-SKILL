> 属官方优秀论文。**其具体获奖等级（国一/国二）未能从官网直接确证**，因此本文档统一表述为

## 一、摘要：唯一一次低成本说服评委的机会

> ⚠️ **先纠正一个流传甚广的说法**：「摘要决定生死」「摘要 35 分」**没有官方依据**。
> 官方对摘要只有格式规定（不超一页、含标题关键词），从未给出分值或否决权。
> 摘要之所以关键，是因为它是评委了解你论文的**第一个窗口**——多位有评阅经历的高校教授
> 一致强调「仅仅依靠摘要，就能大概了解文章做的什么问题、怎么做的、结论是什么」。
> 详见 `02-评阅标准与红线.md` §三。

### 1.1 三条摘要的骨架对照

**B060（双路线交叉验证型）**

```

       进行数值计算厚度交叉印证的解决路径。

[问题一] 对于问题一，该方案首先基于碳化硅和硅的先验折射率物理模型

         给出了直接计算外延层厚度的公式；

[问题二] 对于问题二，在……建立的模型上，设计了两个求解路线
         （1）周期波谷直接计算法：……计算多组厚度 d 并用统计方法
             给出最终厚度计算值为 7.544μm
         （2）牛顿迭代反演法：……给出厚度 d 的迭代解：7.295μm
             作为直接计算值 7.544μm 的较好印证值

[问题三] 对于问题三，解答路线是（A）……得到评判指标 G，
         （B）……给出附件 3、4 数据的厚度计算值为 3.453μm（直接计算）
             和 3.414μm（牛顿迭代），
         （C）……对附件 1、2 所测数据评估多光束效应，
         （D）……最终可信的厚度值是 7.455μm

[关键词] （摘要页末）
```

**B195（迭代降维型）**

```
[总起] 企业生产过程中需要考虑次品抽样、生产流程质量控制中的决策等问题。
       这些是关于企业效益的极具经济价值的关键难题，而其本质上是一个
       多阶段策略优化问题。本文综合假设检验、收益期望、贝叶斯理论等
       数理统计方法，建立多阶段优化模型，运用模拟仿真，线性模拟退火
       算法完成了模型求解，得到了不同情况下的最优决策。

[问题一] 对于问题一（以及之后的所有问题），在计算机上进行模拟仿真。
         根据实际现象规律，生成一组正态分布数据，并根据标准正态分布、
         给定的次品率得到次品的数据范围，再比较不同的抽样结果得出优劣。
         结果表明实际应用过程中经常使用的 (n,c) 抽样法较优……本文采用
         两种计算方法得出了一系列 (n,c) 值，列举一部分值如下：
         (1)[78,12],[85,13]；(2)[68,10],[65,3],[78,4]。

[问题二] 对于问题二，分析生产全流程，利用迭代思想将流程决策问题转化为
         多阶段问题，降低仿真难度。利用全概率公式考虑零件组合成为正品的
         概率……建立以最大净利润为目标函数优化模型……确定 6 个决策变量：
         ……发现所有决策结果均为 0、1 事件。且当调换费用远大于成品检查
         费用时，期望进行成品检查，当次品率较大时，期望检查购买所得零件。
         列出情形一的答案如下：只检验零配件 1，不检验零配件 2，不检验成品，
         对所有不合格成品进行拆解，不检验拆解后得到的零配件，检验拆解后
         得到的零配件 2。

[问题三] 对于问题三，生产流程添加半成品环节，通过对半成品进行分类，
         修改问题二的多阶段问题……确定 16 个决策变量，将其按顺序排成
         新的决策矩阵。沿用问题二结论，所有决策为 0、1 事件，比较所有
         可能决策方案，得到两个最优的决策矩阵（1 代表检验或拆解，
         0 代表不检验或不拆解）和净盈利值（仿真初始配件数为各 10000 件）：
         [111111100011111],448518；[1111111111100001],435188。

[问题四] 对于问题四，对于扰动问题，本文使用贝叶斯统计公式，结合先验信息
         （可能的次品率分布）和抽样数据（似然概率分布，在本题中为二项分布）
         来计算后验概率分布，即零件真实的次品率分布。得到最大可能的置信
         区间，对置信区间内的最大和最小次品率重新代入二三问的模型，给出
         新决策。结果表明在 0.95 的置信区间内，二三题的决策不变，利润值
         产生微小改变，如第三题的两种方案利润值分别变为：448492、436620
         （0.95 置信区间左侧值）；425154、421235（0.95 置信区间的右侧值）。

[关键词] 线性模拟退火  多阶段决策  模拟仿真  贝叶斯统计
```

**B196（模型名前置型）**

```
[总起] 在当前市场竞争愈发严峻的大环境下，企业如何在确保产品品质的前提下
       有效降低生产成本，已成为其持续发展与立足市场的核心议题。本文以
       一家电子产品制造企业为例，深入分析其在生产流程中需要做出的策略选择。

[问题一] 问题一中，针对供应商提供的零配件次品率，我们设计了基于正态分布
         近似的抽样检测方案。首先，假设合格品和次品分别以 0 和 1 来标定，
         则可认为次品的分布服从二项分布规律。接着，根据棣莫弗-拉普拉斯定理，
         结合生产问题的具体背景，将次品率的分布近似认为是正态分布。由于
         数学期望已知而方差未知，我们将其构造为 t 分布，以便进行假设检验。
         通过设定原假设和备择假设，选择显著性水平，并根据抽样检测结果
         计算 t 统计量，我们可以判断次品率是否超过标称值。最终得到，
         在 90% 的置信度下，需要抽取 1600 个零配件进行检测，若不超过
         176 个次品，则可以接受这批零配件用于生产；在 95% 的置信度下，
         需要抽取 2646 个零配件进行检测，若不超过 291 个次品，则可以接受。

[问题二] 问题二中，针对企业生产过程中的决策问题，我们建立了决策树模型，
         并采用蒙特卡洛模拟和蚁群算法进行求解。首先，将生产过程分解为
         一系列决策节点……然后，计算每条路径的成本和收益，从而得到每条
         路径的利润。通过随机模拟所有可能的决策路径，并计算每条路径的
         期望利润，我们可以找到最大化利润的路径。为了进一步提高求解效率
         和解的质量，我们引入了蚁群算法对蒙特卡洛模拟进行优化……
         例如，问题二的情况一中，最优决策为对零件 1 进行检测，
         对零件 2 不进行检测，对成品不进行检测，对不合格成品进行拆解。
         这样可以在 1000 次采购 2000 个零件 A 和 B 进行制作售卖的情况下，
         获得平均利润 35934 元。

[问题三] 问题三中，针对多工序、零配件的生产流程，我们提出了基于遗传算法
         的优化方案。首先，建立了决策树模型，并采用蒙特卡洛模拟方法进行
         初步决策分析。然后，引入遗传算法进行优化……例如，针对某种多工序、
         零配件的生产流程，最优决策为对 8 种零件均进行检测，对 3 种半成品
         进行检测，对成品进行检测，对不合格成品进行拆解，这样可以在
         1000 次购入 15000 个零件 1~8 的情况下，获得平均利润 813682 元。

[问题四] 问题四中，通过对基于 3σ 准则的实际次品率分析，探讨了在抽样检测
         条件下企业生产决策的鲁棒性。通过对比 95% 和 90% 置信度下的最优
         决策分布发现，在次品率较高时，决策倾向于更多的检测操作以减少次品
         带来的损失。进一步分析了在不同次品率条件下各决策分支对利润的影响，
         发现零件 3、4、8 检测以及成品检测对次品率变化较为敏感。综合考虑，
         在抽样检测条件下，建议检测所有零件与半成品，不检测成品，
         并拆解所有次品，以确保在极端情况下仍能获得可观利润并降低调度
         损失的风险。

[关键词] 假设检验  蒙特卡洛模拟  蚁群算法  遗传算法  精英策略  3σ原则
```

### 1.2 从三条摘要里提炼的「获奖摘要公式」

**结构公式（段数固定）**

```
第 1 段（总起，2-4 句）  背景一句 + 本文用了哪些方法一类 + 解决什么问题
第 2 段（问题一）        针对问题一，<方法>，<怎么做>，<得到什么数值>
第 3 段（问题二）        针对问题二，……
第 4 段（问题三）        针对问题三，……
第 5 段（可选，评价一句）最后，我们对模型进行评价……（B060 无，B195/B196 有）
关键词一行               3-6 个，模型名 + 算法名 + 核心概念
```

**每个问题段落的三件套（缺一不可）**

| 要件 | 要求 | 反例（扣分写法） |
|------|------|-----------------|
| **① 模型/方法名** | 写出具体名称：`t 分布假设检验`、`决策树模型`、`线性模拟退火`、`牛顿迭代反演法` | 「建立了数学模型」「运用了相关算法」 |
| **② 求解步骤** | 2-3 句说清怎么算：先干什么、再干什么 | 只有模型名字，没有过程 |
| **③ 数值结果** | **必须带数字和单位**：`1600 个`、`176 个次品`、`35934 元`、`7.544μm`、`0.95 置信区间` | 「结果较好」「方案较优」「得到满意结果」 |

**B196 的段落签名（最值得抄的结构）**

```
问题X中，针对<对象>的<问题性质>，我们<设计了/建立了>基于<方法>的<模型名>。
首先，<第一步>……接着，<第二步>……然后，<第三步>……
例如，<一个具体算例>，最优决策为<具体决策>，这样可以在<条件>下，
获得<数值结果>。
```

这个签名的威力：**「例如」后面必须挂一个真实算例 + 一个真实数字**。评阅老师扫读摘要时，眼睛就停在这个数字上。

### 1.3 摘要的三个高频雷区

1. **背景段写成赛题复述。** B196 第一段只有 2 句，第二句立刻进入「本文以一家电子产品制造企业为例」。背景不是越多越好，超过 4 句就挤掉了结果的空间。
2. **只写模型不写结果。** 每问必须以数值/方案收尾。没有数字的摘要段落等于空转。
3. **各问之间没有递进关系。** 优秀摘要会显式写出依赖：「沿用问题二结论」「将流程决策问题转化为多阶段问题，降低仿真难度」「作为直接计算值 7.544μm 的较好印证值」。写出问题之间的**数学依赖**，而不是并列罗列。

### 2.1 逐问分析的写法（B195 / B196 的 2.x 节）

问题分析部分是**展示建模品味**的地方。B195 的问题三分析只有一段，但信息密度极高：

```
显然问题三是对问题二的推广，对于每种零配件、每种半成品、成品都存在一个
决策参数，即是否检验……第一次循环拆解成品后得到的半成品、组装成成品前
剩下的半成品（已检验或未检验）……则进入第二个循环，得到第二个盈利值，
最后得到次品并重新进入循环。设立决策变量矩阵后，再仿照问题二的思路
进行模拟退火，得到最优的决策矩阵。
```

拆解它的写法：
1. **第一句定性关系**：「显然问题三是对问题二的推广」——一句话锚定问题之间的数学关系。
2. **第二句枚举决策维度**：「每种零配件、每种半成品、成品都存在一个决策参数」——把问题的规模讲清楚。
3. **第三句讲循环/依赖结构**：这是本问的难点所在。
4. **最后一句给路线**：「仿照问题二的思路进行模拟退火」——复用 + 微调，不推倒重来。

**这就是问题分析的正确颗粒度：不讲公式，只讲「为什么这样建模」。**

### 2.2 模型假设的写法

**B195（6 条，全部具体）**

```
（1）假设零件的次品和正品随机分布，以避免次品的集中扎堆情形。
（2）假设半成品和产品的制作过程中，由于工艺出现次品的概率是随机的。
（3）检测产品半成品和零件时，若部分检测，则随机地选择部分零件检测。
（4）假设若不能回收零件、半成品和产品的次品，则直接丢弃不会造成
     环境污染等回收费用。
（5）假设生产环境中的多个环节都会影响半成品、成品的次品率，
     但均抽象成一个次品率。
（6）假设生产规模较大，本文仿真起始均使用 10000 套零件。
```

**B196（4 条，全部服务于模型可解性）**

```
1. 零件和成品只有两种状态：零件和成品只有合格品和次品两种状态，
   没有其他中间状态，即服从二项分布。
2. 成本和收益固定：生产成本和产品收益是固定的，不随生产规模和
   市场环境的变化而变化。
3. 线性生产流程：生产流程是线性的，即零件经过检测、装配、成品检测、
   拆解等环节后，最终成为合格产品或次品。
4. 算法参数：模型中涉及多个算法参数，例如蚁群算法中的信息素浓度、
   遗传算法中的交叉概率和变异概率等，这些参数的设置需要根据实际
   情况进行调整。
```

**共同特征**：
- **每条假设都对应一个后续用到的模型机制**。B196 第 1 条「服从二项分布」直接支撑问题一的假设检验；B195 第 6 条「仿真起始 10000 套」直接对应仿真参数的设定。
- **每条都是可检验的**。对比反例：「假设其他条件不变」——这句话什么信息都没给。
- **数量克制**：4-6 条。不要超过 8 条。

**共同特征中的一条红线**：假设不是免责声明。写了「假设次品率不变」，正文就不能出现「次品率在 0.05-0.15 间波动」的结论而不做灵敏度分析。

### 2.3 符号说明的写法

**B196（含单位列，推荐）**

| 符号 | 说明 | 单位 |
|------|------|------|
| $N_i$ | 第 i 种零件的购买数量 | 个 |
| $C_i, c_i$ | 各生产阶段的成本 | 元 |
| $D_i, d$ | 决策变量，取 0 或 1 | \ |
| $P_i$ | 第 i 种零件中能够参与装配的零件占所有购买零件的比例 | \ |
| $\alpha,\beta,\gamma$ | 均为对应物品的次品率 | \ |

**B060（按字母族分组，适合符号多的物理题）**

```
拉丁字母
  λ      真空波长，单位：cm
  σ_m    以 m^-1 计的波数，σ_m = 100ν̃
  d      薄膜厚度，单位：μm
希腊字母
  β      单程相位，β = (2π/λ) ñ₁ d cos θ₁
  ...
```

**写法要点**
- **有单位的必须标单位**，无量纲的用 `\` 或留空。
- **符号多于 ~15 个时**，按字母族或按物理量类别分组，否则表格会长到难看。
- **符号表里出现的每一个符号，正文必须用到**；正文出现的核心符号，符号表必须有。这是评委常查的一致性点。

### 2.4 模型建立与求解的写法

**B196 5.2.2「利润值计算」的结构（可直接迁移的模板）**

```
1. 成本计算
   （1）零件购买成本 C₁ → 公式 (8) → 说明各符号含义
   （2）零件检测成本 C₂ → 公式 (9)
   （3）成品装配成本 C₃ → 公式 (10)(11)
   （4）成品检测成本 C₄ → 公式 (12)
   （5）成品拆解成本 C₅ → 公式 (13)
   （6）用户调换成本 C₆ → 公式 (14)
2. 收益计算
   收益仅与客户所收到合格品的数量有关 → 公式 (15)
3. 利润计算
   收益值减去成本即为利润
```

**这个结构为什么有效**：
1. **加性分解**：把总目标拆成互不重叠的分项，每一项一个公式。
2. **每项公式后立刻解释符号**：「其中 $N_i$ 表示第 i 种零件的购买数量，$W_{1i}$ 表示第 i 种零件的购买单价。」
3. **决策变量显式编码**：$D_{1i}$ 取 0 为不检测、1 为检测。把管理决策翻译成 0/1 变量，是决策类题目获奖论文的标准动作。
4. **推导链闭合**：成本 → 收益 → 利润，三步走完，不跳步。

**B060 的「双路线交叉验证」（物理/机理类题目的杀手锏）**

问题二同时给出两条独立解法：
- 路线（1）周期波谷直接计算法 → $d = 7.544\,\mu m$
- 路线（2）牛顿迭代反演法 → $d = 7.295\,\mu m$

然后**把两值并列呈现，互为印证**，最终在问题三给出「最终可信的厚度值 7.455μm」。

**为什么这招强**：单条解法永远可能算错，两条独立路径收敛到同一量级，可信度是指数级提升的。评阅老师看到「交叉印证」四个字就知道作者有科学素养。**凡是存在两种以上独立求解路径的题目，都值得做这一手。**

### 2.6 灵敏度/鲁棒性分析的写法

B196 把鲁棒性分析做成了问题四本身：

```
通过对比 95% 和 90% 置信度下的最优决策分布发现，在次品率较高时，
决策倾向于更多的检测操作以减少次品带来的损失。进一步分析了在不同
次品率条件下各决策分支对利润的影响，发现零件 3、4、8 检测以及成品
检测对次品率变化较为敏感。
```

**三个动作**：
1. **对比不同置信水平**（95% vs 90%）→ 决策是否改变？
2. **指出敏感变量**（零件 3、4、8 的检测）→ 哪些参数最要命？
3. **给出鲁棒结论**（建议检测所有零件与半成品）→ 在极端情况下仍可获利。

**关键**：灵敏度分析的结论必须落到「**决策是否改变**」或「**方案是否仍然可行**」上，而不是只给一张扰动曲线图。

## 三、从三篇论文里学到的「隐形加分项」

| 加分项 | 出处 | 具体做法 |
|--------|------|---------|
| **决策变量 0/1 化** | B195、B196 | 把「检测/不检测」编码为 $D_i \in \{0,1\}$，让决策问题变成组合优化，可直接套算法 |
| **多阶段 / 迭代降维** | B195 | 「利用迭代思想将流程决策问题转化为多阶段问题，降低仿真难度」——难度管理的显式表达 |
| **交叉验证** | B060 | 两条独立路线给出两个数值，互为印证 |

## 四、必须避开的反模式（来自真实论文的问题）

### 4.1 ⚠️ 直接抄录赛题原文（B196 的隐患）

B196 的 5.1.1 节开头：

```
二项分布属于离散概率分布范畴，它刻画了一个随机变量在一系列固定数量
的独立试验中所呈现的分布特性。在这些试验中，每一试验均仅有两个互斥的
结局，习惯上分别定义为"成功"与"失败"。此外，每一试验中"成功"事件
发生的概率保持恒定。该分布模型用于描述在给定试验次数下，实现特定数量
"成功"事件的概率结构。
```

5.2.1 节：

```
决策树法是一种通过树状图形来分析和选择决策方案的方法，它将决策问题
分解为一系列节点和分支，每个节点代表一个决策或机会，分支则表示不同
选择带来的结果。通过计算各结果的期望值，决策者可以从中选出最优的
决策路径。
```

这两段是**教科书式的方法介绍**，本身不违规，但它占用了大量篇幅却不产生任何「本文做了什么」的信息。评委的耐心有限，这类段落越长，真正属于你的贡献被稀释得越厉害。

**处理原则**：
- 通用方法的介绍压到 **1-2 句 + 一个文献引用**，例如：「决策树法通过计算各分支期望值选择最优路径[3]。」
- 把篇幅留给**本题特有的建模动作**：「在处理问题二时，我们将其抽象化为四个关键的决策节点：……」
- **绝对不能**整段复制赛题背景描述文字——这是查重检测的直接目标（见 `02-评阅标准与红线.md` §四）。

### 4.2 其它高频反模式

| 反模式 | 为什么扣分 | 正确做法 |
|--------|-----------|---------|
| 公式堆砌无解释 | 评委无法判断你是否理解 | 每个公式后跟一句「其中 X 表示……」，并说明公式的实际意义 |
| 图无分析 | 图是证据不是装饰 | 正文必须有「从图 X 可以看出……」并给出结论 |
| 符号前后不一致 | 直接暴露不严谨 | 定稿前全文搜索每个符号，确认含义唯一 |
| 结果精度失真 | 「7.5439821μm」的 7 位有效数字毫无意义 | 按物理量/数据的实际精度保留（本题数据精度决定有效位） |
| 优缺点写成套话 | 「精度高、适用性强」放在任何论文里都成立 | 优缺点必须绑定本文模型的具体机制（见 `04-分章写法.md`） |
| 只做一遍计算就说"模型稳定" | 没有扰动就没有稳定性结论 | 至少给一个参数变化范围或对照方案 |

## 五、这三篇论文没做到的（也是你该超过的地方）

诚实记录局限，避免把获奖论文当完美范本：

1. **B196 篇幅偏短（28 页）**，部分推导跳步（如公式 (15) 收益计算直接给出，未解释为何「收益仅与客户所收到合格品的数量有关」）。跳步在有评委质疑时是风险。
